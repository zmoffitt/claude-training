# Start Here

Start with the Claude training program, or use the reference pages while you work.

## Learning mode

Go through the sessions in order. Each one builds on the last, ends with a practice assignment, and links forward to the next.

### Claude

1. **[Session 1: Foundations](/docs/training/claude-code/session-1)** — what Claude is, how context works, models and effort, plan mode
2. **[Session 2: CLI Workflows & Project Context](/docs/training/claude-code/session-2)** — permissions, `CLAUDE.md`, hooks, subagents
3. **[Session 3: Extending Claude](/docs/training/claude-code/session-3)** — skills, plugins, MCP, connectors, scheduled tasks

Sessions 4 (agents) and 5 (capstone) are in progress.

### Optional track: Codex & ChatGPT

1. **[Foundations & ChatGPT](/docs/training/codex-chatgpt/session-1)** — context, projects, model selection, and evidence-based verification
2. **[Codex Workflows & Project Context](/docs/training/codex-chatgpt/session-2)** — setup, `AGENTS.md`, permissions, implementation, and review
3. **[Skills, Connections & Automation](/docs/training/codex-chatgpt/session-3)** — reusable skills, MCP, plugins, scheduled tasks, and evaluation

Start with the [track overview](/docs/training/codex-chatgpt) for prerequisites and a mapping from Claude concepts.

## Reference mode

You're mid-task and need one answer.

- Press `⌘K` (or `/`) and type what you're looking for. Every page is indexed.
- **[Configuration](/docs/configuration/claude-md)** holds the `CLAUDE.md` template, editor setup, and team conventions.
- **[Tips & Tricks](/docs/tips/effective-prompts)** holds prompts that work and the pitfalls that cost people a day.
- **[Best Practices](/docs/best-practices/code-review)** covers review, security, and fitting AI tools into the workflow.

Every content page has breadcrumbs, a "Where to go next" section, and ←/→ paging, so you can land anywhere and still find your footing.

## Tools covered

Claude is the primary training program. The Codex/ChatGPT track provides an additional path for teams using OpenAI tools. GitHub Copilot has its own page, and the prompt-engineering guidance applies across assistants.
