# Editor Setup

Extensions and settings for VS Code and JetBrains, and the Claude Code install for your terminal.

## VS Code

### Extensions

| Extension | Purpose |
| --- | --- |
| [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot) | Inline code completions |
| [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat) | AI chat sidebar |
| [Claude Code](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code) (Anthropic) | Claude Code integration |

### Recommended settings

```json
{
  "editor.inlineSuggest.enabled": true,
  "github.copilot.enable": {
    "*": true,
    "plaintext": false,
    "markdown": true
  }
}
```

## JetBrains IDEs

### Plugins

1. Open **Settings > Plugins > Marketplace**
2. Install [GitHub Copilot](https://plugins.jetbrains.com/plugin/17718-github-copilot) and [Claude Code](https://plugins.jetbrains.com/search?search=Claude%20Code)
3. Restart the IDE
4. Sign in via **Tools > GitHub Copilot > Login**; Claude Code signs in on first launch

## Terminal (Claude Code)

Claude Code runs in your terminal. Use the native installer, which auto-updates:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Homebrew (`brew install --cask claude-code`) and WinGet (`winget install Anthropic.ClaudeCode`) also work but don't auto-update. The npm package (`npm install -g @anthropic-ai/claude-code`) still exists and installs the same native binary.

Then launch it in a project:

```bash
claude
```

The VS Code extension adds a chat panel with inline diffs, and the Claude Desktop app's **Code** tab gives you the same engine with a file browser, diff viewer, and terminal, with no separate install.
