# GitHub Copilot

<ReadTime minutes={3} />

Autocomplete that reads your file. Useful every day, and not the same job as an agent.

## Where it fits

Copilot lives in the editor and predicts the next lines from the file you have open. That makes it the right tool for the typing half of the work: finishing a function whose shape is obvious, filling in a test from its name, writing the fourth Terraform resource that looks like the first three. It is the "Human IN the loop" era from Session 1, and it stays useful after you move on, because most of a day is still typing.

What it does not do is read the rest of the repo, run the tests, or hold a plan. When the task is "make the login flow support SSO" rather than "complete this line", switch to Claude Code and <Term id="plan-mode">plan mode</Term>.

## Setup

### VS Code

1. Install the **GitHub Copilot** extension from the VS Code marketplace
2. Sign in with your GitHub account
3. Copilot suggests completions as you type; `Tab` accepts, `Esc` dismisses

### JetBrains

1. **Settings > Plugins > Marketplace**, install **GitHub Copilot**
2. Restart the IDE and sign in via **Tools > GitHub Copilot > Login**

## Getting good completions

Copilot only sees the open file and a little around it, so give it something to read.

- **Write the comment first.** A one-line intent above the function is the prompt: `// return the CA policies that exclude the break-glass account`.
- **Name things properly.** `stalePolicies` gets a better completion than `arr`.
- **Give it the signature.** Type the function name and parameters, let it fill the body, then read the body.
- **Keep a reference open.** A sibling file with the pattern you want is the strongest context Copilot has.
