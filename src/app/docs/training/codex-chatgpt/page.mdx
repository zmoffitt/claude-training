## Start here

No Claude experience is required. Bring access to your organization-approved ChatGPT or Codex environment, a disposable Git repository, and sanitized training material. Session 1 works without a local coding setup; Session 2 includes setup guidance. Each session ends with an assignment and explicit review criteria.

The exercises use synthetic incidents and local changes. Product availability and managed permissions vary by account. Check the linked official documentation against the client you use; this track was reviewed on **November 7, 2026**.
