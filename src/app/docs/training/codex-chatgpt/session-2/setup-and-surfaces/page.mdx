# Set Up Codex & Choose a Surface

Start in the intended repository and confirm what the session can access.

Use the [official CLI installation guide](https://learn.chatgpt.com/docs/codex/cli) for your operating system, or use the supported desktop or IDE workflow. Follow your organization's sign-in and software-installation requirements.

```bash
cd path/to/training-repo
git status --short
codex
```

In the CLI, `/status` shows session configuration, `/permissions` controls access, `/model` selects the model and effort, and `/init` can draft `AGENTS.md`. Review generated instructions before committing them. [Codex CLI reference and setup](https://learn.chatgpt.com/docs/codex/cli).

## First task: orientation

```text
Inspect this repository without editing it. Identify its entry points,
build and test commands, applicable AGENTS.md guidance, and current
working-tree changes. Cite the files that establish each answer.
```

Check that Codex found real commands rather than assuming every project has `npm test`. Record pre-existing changes so you can distinguish them from the exercise patch.

## Choose where the work runs

Use the CLI for terminal workflows, the IDE for code alongside editor context, and the desktop workflow for organizing longer tasks. Remote coding requires an explicitly configured cloud environment; local dependencies and credentials should not be assumed to exist there. See the [official quickstart](https://learn.chatgpt.com/docs/quickstart).

**Before editing:** establish a clean checkpoint or a separate training branch according to team practice. Never discard someone else's work to make the exercise easier.
