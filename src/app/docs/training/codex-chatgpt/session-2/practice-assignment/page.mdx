# Practice: A Reviewable Codex Change

Complete one bounded repository task from orientation through review.

Choose a small bug or documentation defect in an approved repository.

1. Inspect the repository and draft or improve its `AGENTS.md` using verified commands.
2. Record current changes and establish an isolated branch or checkout.
3. Give Codex an outcome, constraints, and acceptance criteria.
4. Review the plan when behavior or scope is uncertain, then authorize implementation.
5. Inspect the final diff, run the relevant checks, and perform a separate review pass.

## Submit for review

Provide the task brief, instruction change, patch, check output, and a short handoff. Include one thing Codex initially misunderstood and how you corrected it.

**Pass criteria:** the diff is focused, checks exercise the requested behavior, unrelated work is preserved, and the report distinguishes passed, failed, blocked, and unrun checks.
