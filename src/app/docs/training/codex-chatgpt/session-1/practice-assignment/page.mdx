# Practice: A Grounded Engineering Answer

Bring evidence of one successful task and one useful correction.

Before Session 2, complete one task using sanitized material you are allowed to share.

1. Choose a runbook explanation, incident summary, or architecture question.
2. Write a task brief with a source, constraints, and acceptance criteria.
3. Use a ChatGPT project if you expect related follow-up tasks.
4. Check three factual claims against the source and correct any unsupported conclusions.
5. Write a short handoff that Codex could use to investigate the related repository.

## Submit for review

Bring the original prompt, final artifact, three checked claims, and one limitation. Include a short note on where you stored reusable instructions.

**Pass criteria:** the answer is traceable to supplied evidence, missing information stays visible, and the next task has a checkable finish line. A polished answer without sources does not meet the exercise goal.
