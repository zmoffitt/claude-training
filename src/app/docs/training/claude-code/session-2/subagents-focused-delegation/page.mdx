# Subagents: Focused Delegation

Spawn a focused helper, get results back, move on.

<Subagents />

**Built-ins and your own.** Claude Code ships `Explore` (read-only search), `Plan` (research for plan mode), and `general-purpose` (full tool set). Define custom ones as Markdown files with frontmatter in `.claude/agents/`, pinning a model, <Term id="effort">effort</Term>, tools, and permission mode per role.

**Pick the model per role.** A subagent with no `model` in its frontmatter runs on the session's model, and so do the built-in `Explore` and `Plan`, so a session on Opus pays Opus prices for every file search. Set `model: haiku` or `model: sonnet` on helpers that search, read logs, or summarize, where a wrong answer is cheap to spot, and keep code edits and judgment calls on the main model. To make exploration cheap everywhere, define your own subagent named `Explore` with `model: haiku`. `CLAUDE_CODE_SUBAGENT_MODEL` sets the default for subagents that do not name a model, and a `model` in the definition still wins. It does not reach the built-in `Explore` and `Plan`; adding `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` applies it to the built-ins and overrides pinned definitions too. The [subagents reference](https://code.claude.com/docs/en/sub-agents) lists the full resolution order.
