# Agent Teams: Coordinated Work

<ReadTime minutes={3} />

Multiple independent Claude instances that self-coordinate via a shared task list.

<AgentTeams />

**Experimental and off by default.** Set `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` in your environment or `settings.json`. Each session has one implicit team: ask the lead to "spawn three teammates" and it names them, assigns tasks, and synthesizes results. Teammates don't survive `/resume`, and they use several times the tokens of a single session, so start with research and review work before parallel implementation.
