# Thinking Effort & Quotas

<ReadTime minutes={2} />

Effort controls how deeply Claude reasons before responding. In claude.ai it is a slider; in Claude Code it is `/effort` with five levels: `low`, `medium`, `high`, `xhigh`, `max`.

**Know the defaults.** Opus 5.5, Sonnet 5.5, and Haiku 5.5 default to `medium`; older models default to `high`. `xhigh` is the sweet spot for hard agentic coding. Type `ultrathink` anywhere in a prompt to run that one turn at `xhigh`, or pass `--effort xhigh` when you launch. Subagents and skills can pin their own effort in frontmatter, so a cheap helper stays cheap.

<br />
<Callout variant="warning" title="Why does this matter?" align="left">
  Higher effort = more tokens = more quota consumed. Raise effort when a wrong
  answer is expensive; drop it for routine work. Be efficient with context to
  stretch your usage.
</Callout>
