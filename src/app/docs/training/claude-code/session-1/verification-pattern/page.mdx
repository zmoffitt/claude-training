# The Verification Pattern

Ask Claude to self-check — the single biggest quality improvement you can make.

## Create then review

```text
...then review it for accuracy and completeness before saving
```

## Create then test

```text
...then spot-check 5 random rows against the source data
```

## Create then compare

```text
...then compare it against the original to make sure nothing was missed
```

## Multi-step checkpoint

```text
After each section, pause and verify before moving on
```

**Make it mechanical.** In Claude Code, a `PostToolUse` <Term id="hook">hook</Term> that runs your linter or test suite after every edit is the same pattern with no prompting required. Session 2 covers hooks.
