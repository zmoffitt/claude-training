# Choosing the Right Model

<ReadTime minutes={3} />

Match the model to the task — the biggest lever for managing token consumption.

**The current lineup is the Claude 5 family.** Opus 5.5 is the default on every plan and in Claude Code. Sonnet 5.5 and Haiku 5.5 sit below it; Fable 5.1 sits above it, selected with `/model fable` (or `best`, which falls back to Opus where Fable is unavailable). Run `/model` in Claude Code to see what your plan offers.

## Legacy models you'll still meet

The previous generation is still served, and some providers resolve the `opus`, `sonnet`, and `haiku` aliases to it. If `/model` shows one of these, you're usually on a third-party platform or an older org default.

<div className="max-w-2xl lg:max-w-3xl">

| Model | Price (in / out per 1M) | Where it still shows up |
| --- | --- | --- |
| Fable 5 | $10 / $50 | What `fable` resolves to in Claude apps gateway sessions |
| Opus 5 | $5 / $25 | Older Enterprise org defaults; Opus 5.5 is cheaper and stronger |
| Opus 4.8 / 4.7 | $5 / $25 | 1M context by default; fast mode on 4.8 is retired on 30 Nov 2026 |
| Opus 4.6 | $5 / $25, 200K unless `[1m]` | The `opus` alias on Microsoft Foundry |
| Sonnet 5 | $2 / $10 | The auto-mode classifier model |
| Sonnet 4.6 | $3 / $15, 200K unless `[1m]` | The `sonnet` alias on Claude Platform on AWS |
| Sonnet 4.5 / Haiku 4.5 | 200K only | The `sonnet` and `haiku` aliases on Bedrock, Google Cloud, and Foundry |

</div>

<br />
<Callout variant="info" title="Rule of thumb:" align="left">
  Stay on Opus 5.5 for interactive work: it is the default, and lower effort on
  Opus often beats a smaller model at high effort. Drop to Sonnet or Haiku for
  subagents, bulk jobs, and scheduled tasks where volume matters more than
  depth. Reach for Fable only when Opus is not getting there. In Claude Code,
  `/model opusplan` keeps Opus for plan mode and switches to Sonnet to execute.
</Callout>
