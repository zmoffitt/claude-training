# Plugins & Marketplaces

A plugin bundles skills, subagents, MCP config, and hooks into one install. A marketplace is where a team publishes them.

## What's in a plugin

- One or more **skills** (<Term id="skill-md">`SKILL.md`</Term> files)
- Optional <Term id="subagent">**subagents**</Term> with focused prompts
- Optional **MCP server** config
- Optional <Term id="hook">**hooks**</Term> and slash commands
- Versioned, distributed via marketplaces

## Install flow

```bash
# Add a marketplace
/plugin marketplace add org/plugins

# Browse and install
/plugin install iam-tools@org-plugins

# List what's installed
/plugin list
```

<Callout variant="info" title="Private marketplace = team standardization" align="left">
  Build a single internal plugin repo. Every engineer installs it. New
  conventions, skills, or MCP servers ship through one update — no
  copy-paste, no drift.
</Callout>
