# Built-in Connectors

## Available connectors

| Connector | Surfaces | What it unlocks |
| --- | --- | --- |
| **Google Workspace** | Drive, Gmail, Calendar | Search docs, draft mail, find availability without leaving Claude |
| **Microsoft 365** | Outlook, SharePoint, Teams | Search mail, files, and Teams history. Write tools (send mail, calendar, Teams posts, file edits) exist but are admin-enabled and off by default |
| **GitHub** | Repos, Issues, PRs | Browse code, manage issues, review pull requests inline |
| **Slack** | Channels, DMs | Search history, summarize threads, post updates with consent |

## How to enable

Settings → Connectors → pick provider → OAuth flow in your browser → scope the permissions you grant. Revoke any time from the same panel or the provider's admin console.

<Callout variant="warning" title="Mind the scope" align="left">
  Connectors run with **your** identity. Anything Claude reads through them
  follows your existing permissions — no more, no less. Write tools are a
  second gate: an org Owner enables them, Enterprise admins can limit them to
  a custom role, and every write asks for approval before it runs. Privileged
  accounts should connect from a least-privileged Claude session.
</Callout>
