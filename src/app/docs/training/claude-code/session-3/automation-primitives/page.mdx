# Which "Scheduled Task" Did You Just Create?

<ReadTime minutes={3} />

Four automation primitives — the **Monitor tool**, **`/loop`**, a **Desktop local task**, and a **cloud scheduled task** — know which surface you're actually on. Claude Code's `/schedule` always creates a cloud task; the Desktop app's **New task** button asks you to pick **Local** or **Cloud**.

<div className="max-w-2xl lg:max-w-3xl">

| Primitive                            | Create via                                                                                       | Runs on                                                  | Survives closed laptop?     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------- | --------------------------- |
| **Monitor tool**                     | Called inline by Claude in a live session — not user-created. Watches a command's output for up to 30 minutes | Background process on your machine, current session only | No                          |
| **`/loop`**                          | `/loop 5m /skill` in any CLI session; minimum 1 minute                                           | Your machine, current session only                       | No                          |
| **Desktop local task**               | Desktop → Code tab → **Scheduled** → **New task** → **Local**; or ask Claude in any Desktop session ("every weekday at 9, …") | Your machine — Desktop must be open and awake; one catch-up run on wake | No (one missed run replays) |
| **Cloud scheduled task** _(formerly routine)_ | Desktop → **New task** → **Cloud**; Claude Code `/schedule`; `claude.ai/code/routines`     | Anthropic-managed cloud infrastructure; minimum interval 1 hour | **Yes**                     |

</div>

<br />

<Callout
  variant="info"
  title="Local or cloud is the only real choice"
  align="left"
>
  Local tasks see your files, MCP servers, and config but need the machine
  awake. Cloud tasks get a fresh clone plus your claude.ai connectors and run
  while you sleep. Cowork used to ship its own `/schedule` skill; typing it now
  just fills in a scheduling request in the same dialog.
</Callout>
