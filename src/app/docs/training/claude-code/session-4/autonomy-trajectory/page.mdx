# The Autonomy Trajectory

<ReadTime minutes={3} />

Three rungs — task execution, human in the loop, human on the loop. Pick the rung per task, not per engineer.

  cards={[

**Autonomy is per-task, not per-engineer.** A senior IAM engineer running CA policy changes belongs at Level 1 for *that* task. The same engineer running access reviews can comfortably sit at Level 3. Pick the rung that matches the *blast radius*, not the seniority.

<Callout variant="warning" title="You can delegate the work, but not the accountability" align="left">
  An agent at Level 3 isn't Claude running on its own — it's Claude running inside guardrails *you* designed, with checkpoints *you* set, against a definition of done *you* wrote. The fluent engineer doesn't ask "can Claude do this?" They ask: "at what autonomy level should this run, and what would it take to get there safely?"
</Callout>
