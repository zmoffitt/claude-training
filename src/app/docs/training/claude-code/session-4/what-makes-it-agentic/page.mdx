## The four-beat loop

<AgentLoop />

The trick isn't building the loop — Claude already does it. The trick is choosing *which beats need a human*, and which can run on rails. That's the autonomy decision.

<Callout variant="info" title="No new app to install" align="left">
  Claude Code, Cowork, and scheduled tasks are *already* agents in this sense — the difference is how much of the loop you let them run before you check in. This session is about widening that window deliberately, with guardrails.
</Callout>
