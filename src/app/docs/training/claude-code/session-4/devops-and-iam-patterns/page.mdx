# DevOps & IAM Patterns That Earn Their Keep

<ReadTime minutes={3} />

Four shapes ready to fork — two DevOps, two IAM. Highest-frequency, lowest-blast-radius first; pick one as your week-1 target.

**DevOps rule of thumb.** Highest-frequency, lowest-blast-radius first. Drift detection runs daily and costs nothing if wrong. Prod deploys run once and cost everything if wrong.

<Callout variant="error" title="IAM red lines" align="left">
  CA writes, PIM activations, role assignments, and group edits stay **Level 1** regardless of agent quality. The value is in the human pause, not the speed.
