# Designing Guardrails

<ReadTime minutes={3} />

Five layers make autonomy *auditable* — instruction, enforcement, reasoning, escalation, and a clear definition of done.

<GuardrailLayers />

The first two layers are framework features (what Claude reads, what permissions enforce). The next two are skill-design discipline (how you write the prompt). The last is workflow discipline (what counts as finished). All five, layered, are what makes a Level 3 task worth running.
